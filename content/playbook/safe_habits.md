# Safe Email Habits and Reporting Playbook

## verify_out_of_band
- **Title:** Verify Unexpected Requests Out-of-Band
- **Body:** If an email asks for a password reset, payment change, sensitive file, or urgent executive favor, confirm the request using a separate trusted channel—such as calling a number from the internal directory or messaging the colleague directly. Never reply to the suspicious email itself to verify its authenticity.

## report_early
- **Title:** Report Suspicious Emails Immediately
- **Body:** Reporting suspicious messages turns every employee into an early-warning sensor for the security team. Use the Report Phishing button as soon as you suspect a message, even if you already clicked a link. Fast reporting helps security block similar messages for other colleagues.

## inspect_before_clicking
- **Title:** Inspect Sender and Destination Before Clicking
- **Body:** Check the full sender address (not just the display name) and hover over any link to inspect the domain. Look closely for subtle character substitutions or extra subdomains. If you need to log in, open a new browser tab and use your saved bookmark instead of clicking the email link.

## no_shame_remediation
- **Title:** What To Do If You Clicked or Submitted Data
- **Body:** If you clicked a suspicious link or entered information on an unfamiliar page, stay calm and report it right away. Disconnect from sensitive workflows if advised, change your password from a trusted device, and notify the security team so they can check for unauthorized activity.
